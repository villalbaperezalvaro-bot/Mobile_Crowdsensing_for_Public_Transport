Instala las siguientes dependencias en la terminal
para que el proyecto pueda funcionar 

# --- Librerías principales ---
pip install numpy
pip install pandas
pip install matplotlib
pip install PyWavelets

# --- PyQt6 (interfaz gráfica) ---
pip install PyQt6
pip install PyQt6-WebEngine

# --- Plotly (gráficas interactivas) ---
pip install plotly

O tambien puedes ejecutar el siguiente comando para poder instalar
todo de golpe 

pip install -r requirements.txt

Asegurate de tener el archivo de requerimientos.txt 
Suerte. Si algo falta preguntame. O nada que un gptzo no resuelva.
